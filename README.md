# PRIMO PATO - API

## Ferramentas utilizadas
- Java 21
- Spring Boot 3.5.6
- Maven
- PostgreSQL
- Swagger
- OpenCage
- Junit5
- JPA
- Lombok
- JWT

## Passos para executar a aplicação

### Build API e instalação de dependências
* ./mvnw clean package install

### Rodar API
* ./mvnw spring-boot:run
